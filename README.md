## Selected Work

### Procedra

**Industrial work-instruction drafts, with source context and expert review.**

I designed and developed the application end to end: document retrieval, structured generation, video-processing workflows, editing, review, version history, and execution checklists.

The engineering focus is traceability: keeping input claims distinct from verified information, validating structured output, and retaining a record of review decisions. The product is a controlled demonstration prototype; generated instructions require qualified expert review.

`Python` · `FastAPI` · `Pydantic` · `SQL` · `Retrieval` · `Computer vision`
